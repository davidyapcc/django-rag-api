# Home Network Troubleshooting

## Restart order

When the internet drops, restart the modem first and wait two minutes before restarting the router. Restarting in the wrong order can leave the router without an address from the provider.

## Wi-Fi bands

The 2.4 GHz band reaches further and passes through walls better, but it is slower and more crowded. The 5 GHz band is faster but has a shorter range. Put streaming devices close to the router on 5 GHz.

## DNS problems

If websites fail to load but a ping to an IP address works, the problem is usually DNS. Switching the router to a public DNS resolver often fixes it. Flushing the DNS cache on the computer can also help.

## Router placement

Place the router in a central, elevated spot, away from microwaves, thick concrete walls and metal cabinets. Mesh systems help large homes where one router cannot cover every room.

## Security

Change the default admin password on the router. Use WPA3 encryption where devices support it, and WPA2 otherwise. Turn off WPS, because its PIN can be brute-forced.
